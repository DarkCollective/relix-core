# Hosted connector catalog

`relix-connectors.json` is the **hosted, decoupled** connector-plugin catalog
(ADR-0010). Relix fetches it at runtime — when `--download-connectors` is given and
a referenced connection's type has no installed connector — from:

```
https://raw.githubusercontent.com/DarkCollective/relix-core/main/connectors/relix-connectors.json
```

(overridable with `$RELIX_CONNECTOR_CATALOG`, which may be an `https://` URL or a
local file path). Because it is served from `main` rather than baked into a relix
release, a connector plugin can be published and the catalog updated **without
cutting a new relix release**.

## Format

A JSON array of entries; each maps a connector **type token** to the artifacts that
make up the plugin — the thin connector JAR plus the driver/runtime JARs it needs —
each with a SHA-256. `ConnectorPluginLoader` loads every downloaded JAR into one
class loader, so a thin plugin JAR + its dependency JARs work together.

```json
[
  {
    "type": "mongodb",
    "artifacts": [
      { "url": "https://github.com/DarkCollective/relix/releases/download/vX.Y.Z/relix-mongo-connector-X.Y.Z.jar", "sha256": "…" },
      { "url": "https://repo1.maven.org/maven2/org/mongodb/mongodb-driver-sync/5.2.1/mongodb-driver-sync-5.2.1.jar", "sha256": "…" },
      { "url": "https://repo1.maven.org/maven2/org/mongodb/mongodb-driver-core/5.2.1/mongodb-driver-core-5.2.1.jar", "sha256": "…" },
      { "url": "https://repo1.maven.org/maven2/org/mongodb/bson/5.2.1/bson-5.2.1.jar", "sha256": "…" },
      { "url": "https://repo1.maven.org/maven2/org/mongodb/bson-record-codec/5.2.1/bson-record-codec-5.2.1.jar", "sha256": "…" }
    ]
  }
]
```

The thin connector JAR is published as a GitHub release asset; its driver
dependencies are referenced directly from Maven Central. Entries are generated by
`./gradlew :relix-mongo-connector:connectorCatalogEntry -PpluginUrl=<release-asset-url>`
and merged in by the release pipeline (`packaging/scripts/update_connector_catalog.py`).
